

## 🛠️ Commandes Utiles (Anti-sèche)

| Action | Commande |
| :--- | :--- |
| **Voir l'état (fichiers modifiés)** | `git status` |
| **Ajouter des fichiers** | `git add .` (tout) ou `git add le/fichier` |
| **Créer un commit** | `git commit -m "type: message"` |
| **Changer de branche** | `git checkout <nom>` |
| **Créer & changer de branche** |`git checkout -b <nom>` |
| **Récupérer les changements distants** | `git fetch --all` |
| **Mettre à jour la branche courante** | `git pull` |
| **Annuler les modifs d'un fichier** | `git restore <fichier>` |
| **Voir l'historique** | `git log --oneline --graph` |
